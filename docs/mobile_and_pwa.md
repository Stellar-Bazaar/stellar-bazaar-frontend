# Stellar Bazaar Mobile Experience & Progressive Web App (PWA)

## 1. Mobile-First Web3 Design

Stellar Bazaar is engineered for seamless operation on mobile smartphones, tablets, and desktop devices. In mobile environments where browser extension popups can be clunky, Stellar Bazaar provides dedicated touch navigation, deep-link wallet integration, and offline persistence.

---

## 2. Touch Navigation Architecture

### A. Mobile Bottom Dock (`MobileBottomNav`)
- Fixed bottom dock (`fixed bottom-0 inset-x-0 z-40 md:hidden`) providing instant thumb-reach navigation.
- Floating center action button for rapid Demand Circle creation (`+`).
- Real-time badge indicators for active order volume and pending dispute alerts.

### B. Slide-Over Panel (`SlideOverDrawer`)
- Swipe-dismissable right drawer used for circle inspection, merchant bid review, and multi-asset wallet balances without navigating away from the explore view.
- Sticky header and action footer with internal vertical scrolling.

### C. Shimmer Skeleton Placeholders (`SkeletonLoader`)
- Prevents layout shifts during Soroban RPC queries and Horizon balance polling with hardware-accelerated CSS shimmer animations.

## 3. Network Offline Resilience & Horizon Heartbeat

Web3 applications on mobile frequently experience intermittent cell reception or Wi-Fi captive portal delays.

### Architecture:
```
[ Browser online/offline Events ] ──┐
                                     ├──> [ useNetworkStatus Hook ] ──> [ OfflineBanner ]
[ Periodic Horizon HEAD Heartbeat ] ──┘                                        │
                                                                               ▼
                                                                     [ Local Cache Fallback ]
```

1. **`useNetworkStatus` Hook**:
   - Listens to native browser network change events.
   - Pings Horizon Testnet (`/` or `/fee_stats`) every 30 seconds with an abortable HEAD request.
   - Distinguishes complete device offline states from remote Stellar RPC downtime.
2. **`OfflineBanner` Component**:
   - High-contrast alert (`role="alert"`) informing users that transactions are paused while allowing cached browsing.
   - One-click "Retry Connection" action.
3. **`local-cache` Manager**:
   - Type-safe localStorage and sessionStorage manager.
   - Native support for BigInt stroop amounts via `serializeWithBigInt` and `deserializeWithBigInt`.
   - Automatic time-to-live (TTL) eviction.

## 4. Progressive Web App (PWA) & SEP-0007 Support

### Web App Manifest (`public/manifest.json`)
- **Standalone Mode**: Eliminates browser URL bar chrome for a native app feel.
- **Theme Color Synchronization**: Coordinates with the cyan/slate dark mode palette.
- **Protocol Handler Registration**:
  ```json
  "protocol_handlers": [
    {
      "protocol": "web+stellar",
      "url": "/?sep7=%s"
    }
  ]
  ```
  Enables one-tap handling of Stellar transaction requests (`web+stellar:tx?xdr=...`) generated by other Stellar ecosystem apps.

### Native Installation Prompt (`PwaInstallPrompt`)
- Captures `beforeinstallprompt` events without showing intrusive browser popups.
- Offers a discreet floating banner with one-tap installation and 7-day dismissal suppression.
